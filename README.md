# Smart Inventory Management & Replenishment System

A full-stack inventory management application built with React, Django REST Framework, and PostgreSQL.

## Planned Features

- Product and inventory management
- Multi-branch inventory tracking
- Low-stock detection
- Sales history and demand analysis
- Branch-to-branch stock transfer recommendations
- Warehouse replenishment
- Supplier reorder recommendations
- Manager approval workflow
- Notifications
- Inventory analytics dashboard

## Tech Stack

### Backend
- Python
- Django
- Django REST Framework
- PostgreSQL

### Frontend
- React
- Vite
- Material UI

### Deployment
- Docker
- AWS
